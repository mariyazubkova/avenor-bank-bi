# Avenor Bank — аналитика клиентской базы в Power BI

Учебный проект, выполненный в рамках выпускной квалификационной работы на тему **«Применение BI-технологий для аналитики клиентской базы»**.

Проект предназначен для анализа состава держателей кредитных карт, распределения признака дефолта и динамики платёжного поведения с использованием Microsoft Power BI Desktop.

**Avenor Bank — вымышленное название организации, используемое для учебного сценария.** Исходные данные получены из открытого репозитория UCI и не являются данными действующего банка с таким названием.

## Возможности проекта

Отчёт позволяет:

- оценить численность клиентской базы;
- определить количество и долю клиентов с признаком дефолта;
- сравнить возрастные группы;
- рассчитать средний кредитный лимит;
- исследовать суммы платежей по месяцам;
- рассчитать средний платёж на клиента;
- сравнить доли клиентов с задержкой погашения при двух порогах статуса;
- отфильтровать результаты по доступным характеристикам клиентов.

Прототип выполняет описательный анализ. Он не прогнозирует индивидуальную вероятность дефолта и не предназначен для автоматического принятия кредитных решений.

Используется набор **Default of Credit Card Clients**.

- Автор: I-Cheng Yeh.
- Репозиторий: UCI Machine Learning Repository.
- Страница: https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients
- DOI: https://doi.org/10.24432/C55S3H
- Исходный файл: `default of credit card clients.xls`.
- Лист: `Обзор клиентской базы` и `Платёжное поведение`.
- Количество клиентов: **30 000**.
- Период месячных наблюдений: **апрель — сентябрь 2005 года**.
- Территория исходного исследования: Тайвань.
- Валюта денежных показателей: новый тайваньский доллар — **TWD**.

Библиографическая ссылка:

> Yeh, I. (2009). Default of Credit Card Clients [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C55S3H

## Программное окружение

- Операционная система: Windows.
- Основной инструмент: Microsoft Power BI Desktop.
- Подготовка данных: Power Query.
- Расчётные меры: DAX.
- Формат проекта: `.pbix`.

**Версия Power BI Desktop, использованная для итоговой проверки:** `[2.159.883.0 64-bit]`.

## Модель данных

Модель включает две связанные таблицы.

### Клиенты

Одна строка соответствует одному клиенту.

Таблица содержит идентификатор, возраст, кредитный лимит, демографические характеристики, возрастную группу и признак дефолта в следующем месяце.

### Показатели_по_месяцам

Одна строка соответствует сочетанию клиента и месяца.

Таблица содержит:

- код клиента;
- месяц;
- номер периода;
- статус погашения;
- сумму счёта;
- сумму платежа.

Ожидаемый объём — **180 000 записей**: 30 000 клиентов × 6 месяцев.

Связь между таблицами установлена по коду клиента: **«один ко многим»**, с направлением фильтрации от таблицы «Клиенты» к месячной истории.

## Подготовка данных

В Power Query выполнены следующие преобразования:

1. Удалена служебная строка перед заголовками.
2. Назначены заголовки и типы данных.
3. Сформированы клиентская таблица и месячная история.
4. Месячные показатели преобразованы из отдельных столбцов в записи по периодам.
5. Добавлено поле даты месяца.

В модели используются понятные русскоязычные наименования полей, расшифровки категорий и возрастные группы.

Коды образования 0, 5 и 6 объединены в категорию «Не определено».

Для семейного положения используются категории «В браке», «Не в браке» и «Не определено». Последняя объединяет исходные коды 0 и 3. В исходном описании код 3 означает «Другое», поэтому такое объединение является упрощением, принятым в проекте.

Исходные коды сохраняются для проверки преобразований.

## Страницы отчёта

### Обзор клиентской базы

Содержит:

- количество клиентов;
- количество клиентов с дефолтом;
- долю клиентов с дефолтом;
- средний кредитный лимит;
- распределение клиентов по возрастным группам;
- долю дефолта по возрастным группам;
- фильтры по полу и образованию.

### Платёжное поведение

Содержит:

- количество месячных записей;
- динамику общей суммы платежей;
- доли клиентов с задержкой при порогах статуса ≥ 1 и ≥ 2;
- таблицу месячных платежей и среднего платежа на клиента;
- фильтры по полу и возрастной группе.

## Как открыть проект

1. Установите Microsoft Power BI Desktop.
2. Скачайте файл проекта `.pbix` из материалов репозитория или итогового релиза.
3. Откройте его в Power BI Desktop.
4. Для повторного обновления скачайте исходный набор по ссылке UCI и распакуйте файл `default of credit card clients.xls`.
5. В настройках источника данных проекта укажите расположение скачанного файла на своём компьютере.
6. Выполните обновление данных.
7. Сбросьте фильтры и сравните основные показатели с контрольными значениями ниже.

**Имя итогового файла проекта:** `[Avenor_Bank_Analytics.pbix]`.

Локальный путь к исходному Excel-файлу на компьютере автора необходимо заменить своим путём.

Значения приведены для полной базы без пользовательских фильтров.

| Показатель | Ожидаемое значение |
|---|---:|
| Количество уникальных клиентов | 30 000 |
| Количество месячных наблюдений | 180 000 |
| Количество клиентов с дефолтом | 6 636 |
| Доля клиентов с дефолтом | 22,12 % |
| Средний кредитный лимит | 167 484,32 TWD |
| Сумма платежей за сентябрь 2005 года | 169 907 415 TWD |

Количество месячных наблюдений определяется структурой преобразования. Остальные значения рассчитаны по исходному файлу.

При проверке также необходимо подтвердить:

- уникальность кода клиента в клиентской таблице;
- отсутствие повторов сочетания клиента и месяца;
- наличие шести месячных записей на клиента;
- правильное соответствие исходных столбцов месяцам;
- согласованную работу фильтров;
- выполнение условия: доля при пороге статуса ≥ 2 не превышает долю при пороге ≥ 1.

Приведённые ориентиры не заменяют отдельный протокол тестирования.

## Особенности интерпретации

- **Дефолт и задержка погашения — разные показатели.** Дефолт определяется отдельной переменной источника, задержка — месячным статусом.
- Показатели задержки рассчитываются по условиям `статус ≥ 1` и `статус ≥ 2`.
- Средний платёж включает клиентов с нулевым платежом.
- Средний платёж в итоговой строке за несколько месяцев означает сумму за весь период на одного клиента, а не средний месячный платёж.
- Первое число в поле даты обозначает месяц наблюдения, а не фактическую дату всех операций.
- Данные исторические. Выводы не описывают состояние современного банковского рынка.
- Различия между клиентскими группами не доказывают причинную связь.
- Данные об оттоке клиентов в наборе отсутствуют.
